# Phase 85 changelog — canonical source regularity

Phase 85 closes the regularity seam in the autonomous pole-removal argument.
For the canonical reduced logarithmic source `rho = N/D`, it proves the exact
cross identity `N*phi = E(phi)*D`, then Euler-differentiates it to obtain the
reduced presentation

`((E N)D - N(E D))/D^2`

of `eta = E(rho)`.  The key polynomial identity shows that this presentation
agrees with the raw `logarithmicEtaNumerator(phi)/phi^2` wherever the latter is
honestly defined, while remaining manifestly regular at every finite reduced
source-chart point `D(x) != 0`.

No projective geometry, analytic differentiation, Laurent series, or new
axioms are introduced.
