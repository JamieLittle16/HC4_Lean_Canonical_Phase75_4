# Phase 93.3 — rank-two and rank-three local terminal certificates

## Rank two

New module:

    HC4/Newton/RankTwoRepairTerminal.lean

The determinant-zero rank-two Schur branch is not artificially promoted to
rank three.  Under the already-green Phase 91 hypotheses it is locally
terminal, because Lean obtains one of the three rigid homogeneous normal
forms.

The named certificate is

    HasRigidRankTwoTerminal

and the constructor theorem is

    hasRigidRankTwoTerminal_of_schurEntry.

## Rank three

`RankThreeInfinityAssembly.lean` now names the green Phase 88
rational-to-polynomial conclusion as

    HasRankThreePolynomialTerminalCertificate.

The theorem

    hasRankThreePolynomialTerminalCertificate

derives it from the concrete rank-three rational-function equation, and

    hasRankThreePolynomialTerminalCertificate_of_core_det_zero

derives it directly from the substituted core determinant-zero hypothesis.

This phase is deliberately honest about the remaining gap.  The
determinant-zero rank-two branch is locally rigid; the rank-three branch
has a polynomial autonomous terminal certificate.  What remains for the
termination theorem is to prove that a nondegenerate rank-two re-entry
event generated by Phase 92 either:

* produces the next classified Schur/Rees event, or
* strictly decreases the Rees/Newton complexity.

No `sorry`, `admit`, `unsafe`, or new axiom is introduced.
